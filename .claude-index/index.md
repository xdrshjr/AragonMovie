## Project Overview

- **Type:** Fullstack — Python multi-agent CLI pipeline + FastAPI web backend + Next.js web frontend
- **Languages:** Python (~77%, ~114 files), TypeScript (~23%, ~34 files); ~210 tracked files total
- **Frameworks:** FastAPI + Uvicorn, Pydantic v2 / pydantic-settings, httpx / aiohttp, moviepy, loguru, pytest (CLI & backend); Next.js 14.2 App Router, React 18.3, TypeScript 5.3, Tailwind CSS 3.4 (frontend)
- **Entry Points:** `cli.py` (CLI), `backend/main.py` (FastAPI app — `uvicorn backend.main:app`), `backend/run_dev.py` (dev server), `frontend/src/app/layout.tsx` + `page.tsx` (Next.js)
- **External APIs:** Nano Banana Pro & Doubao (image gen), Veo3 & Sora2 (video gen, runtime-selectable), Doubao/Volcano Ark (LLM: script polish, character-consistency & scene-continuity judging), Midjourney proxy (optional)
- **Dual interface:** CLI path `cli.py → ProjectManager → ProjectRunner → Agents`; Web path `Frontend → FastAPI → WorkflowService/QuickModeService → ProjectRunner → Agents`. Both converge at the agent layer.
