## Project Overview

- **Type:** Fullstack — Python multi-agent CLI pipeline + FastAPI web backend + Next.js web frontend
- **Languages:** Python (~73%, 127 files), TypeScript/TSX (~26%, 45 files); 244 tracked files after exclusions
- **Frameworks:** FastAPI + Uvicorn, Pydantic v2 / pydantic-settings, httpx / aiohttp, moviepy, loguru, pytest (CLI & backend); Next.js 14.2 App Router, React 18.3, TypeScript 5.3, Tailwind CSS 3.4, js-yaml (frontend)
- **Entry Points:** `cli.py` (CLI), `backend/main.py` (FastAPI app — `uvicorn backend.main:app`), `backend/run_dev.py` (dev server), `frontend/src/app/layout.tsx` + `page.tsx` (Next.js)
- **External APIs:** Ali Token Plan / DashScope (default text + image + video), Nano Banana Pro & Doubao (image gen), Veo3 & Sora2 (video gen, runtime-selectable), Doubao/Volcano Ark (LLM: script polish, character-consistency & scene-continuity judging), OpenAI-compatible TTS, Midjourney proxy (optional)
- **Dual interface:** CLI path `cli.py → ProjectManager → ProjectRunner → Agents`; Web path `Frontend → FastAPI → WorkflowService/QuickModeService → ProjectRunner → Agents`. Both converge at the agent layer.
- **Runtime model settings:** `.env` supplies defaults; `backend/data/model_settings.json` holds UI/agent overrides and is hot-applied onto both `backend.config.settings` and `config.settings.settings` singletons.
