- **Type:** Fullstack — Python multi-agent CLI pipeline + FastAPI web backend + Next.js web frontend
- **Languages:** Python (~55%, 146 files), TypeScript/TSX (~18%, 47 files), Markdown docs (34 files); 266 indexed files after exclusions
- **Frameworks:** FastAPI + Uvicorn, Pydantic v2 / pydantic-settings, httpx / aiohttp, moviepy 2.x, loguru, pytest + pytest-asyncio (+ Playwright for E2E); Next.js 14.2 App Router, React 18.3, TypeScript 5.3, Tailwind CSS 3.4, js-yaml
- **Entry Points:** `cli.py` (CLI), `backend/main.py` (FastAPI app — `uvicorn backend.main:app`), `backend/run_dev.py` (dev server), `frontend/src/app/layout.tsx` + `page.tsx` (Next.js), `start-dev.ps1` (Windows one-shot launcher)
- **External APIs:** Ali Token Plan / DashScope (default text + image + video), Nano Banana Pro & Doubao (image gen), Veo3 & Sora2 (video gen, runtime-selectable), Doubao/Volcano Ark (LLM: script polish, character-consistency & scene-continuity judging), OpenAI-compatible TTS **or** DashScope-native TTS, Midjourney proxy (optional)
- **Dual interface:** CLI path `cli.py → ProjectManager → ProjectRunner → Agents`; Web path `Frontend → FastAPI → WorkflowService/QuickModeService → ProjectRunner → Agents`. Both converge at the agent layer.
- **Runtime model settings:** `.env` supplies defaults; `backend/data/model_settings.json` holds UI/agent overrides and is hot-applied onto both `backend.config.settings` and `config.settings.settings` singletons.

- **Secrets on disk:** `backend/data/model_settings.json` holds real API keys (git-ignored). Never log or echo it; all UI reads must go through `masked()`/`mask_key()`.
- **`.env.example` hygiene is tested:** `tests/test_backend/test_env_example_hygiene.py` fails the build if credential-shaped placeholders creep back in.
- **Never block the event loop:** composition/ffmpeg/large copies must go through `utils/blocking.py`; `test_execute_runs_composition_off_event_loop` and `tests/test_utils/test_blocking.py` guard it. Breaking this makes every `GET /api/v1/tasks/{id}` poll queue behind the mp4 encode and the UI reports "Generation failed".
- **Abandoned tasks are cancelled:** the idle watchdog (`task_idle_timeout_seconds` 900, sweep every 30s) cancels tasks whose client stopped polling, so API-only callers must still poll or accept cancellation. Manual hooks: `POST /api/v1/tasks/maintenance/sweep`, `POST /api/v1/workflow/cleanup`.
- **Default service selection:** `config/settings.py` defaults `image_service_type` and `video_service_type` to `ali_token_plan`. Ali TTS via the compatible-mode gateway is unavailable, so `services/tts_service.py` resolves `TTS_PROVIDER=auto|openai_compatible|dashscope_native` and fails fast via `reject_broken_speech_gateway()` instead of rendering a silent video.
- **Frontend has no JS test runner:** UI guarantees are enforced by `tests/test_frontend/test_source_contracts.py` (source-level markup assertions) plus the Playwright E2E suite.
- **Test layout note:** run pytest from the repo root; `tests/test_backend/` and `tests/test_frontend/` have no `__init__.py`.
